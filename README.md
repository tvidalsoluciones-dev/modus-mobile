# 🌐 Modus Mobile — Landing Page Comercial

Sitio web oficial de aterrizaje para **Modus Mobile**, diseñado con enfoque mobile-first, diagnóstico interactivo en vivo, tarjetas Open Graph de alta resolución para previsualización enriquecida en WhatsApp y adaptación ergonómica para escritorio con código QR dinámico.

---

## 📁 Archivos Incluidos
* `index.html`: Estructura completa HTML5, diseño responsivo integrado (CSS) y lógica interactiva (JavaScript Vanilla sin dependencias).
* `og_banner.jpg`: Portada cinematográfica (16:9) seleccionada para que WhatsApp y redes sociales rendericen la vista previa enriquecida al compartir el enlace.
* `logo.jpg`: Isotipo maestro de Modus Mobile (2K) utilizado en la barra de navegación y favicon.

---

## 🚀 Despliegue en GitHub Pages

Para publicar esta página en la URL oficial:  
👉 **`https://tvidalsoluciones-dev.github.io/modus-mobile/`**

### Opción 1: Mediante la interfaz web de GitHub
1. Ingresa a tu cuenta de GitHub y crea un nuevo repositorio público llamado **`modus-mobile`** bajo la organización o usuario `tvidalsoluciones-dev`.
2. Sube los archivos de esta carpeta (`index.html`, `og_banner.jpg`, `logo.jpg`).
3. En el repositorio, dirígete a **Settings** > **Pages**.
4. En **Build and deployment** > **Branch**, selecciona la rama `main` (carpeta `/ (root)`) y haz clic en **Save**.
5. En 1 o 2 minutos, tu sitio estará activo en `https://tvidalsoluciones-dev.github.io/modus-mobile/`.

### Opción 2: Mediante Git en consola
```bash
cd "landing_web"
git init
git add .
git commit -m "feat: lanzamiento landing page Modus Mobile Cali"
git branch -M main
git remote add origin https://github.com/tvidalsoluciones-dev/modus-mobile.git
git push -u origin main
```
